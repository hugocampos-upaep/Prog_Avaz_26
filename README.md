# Programación Avanzada - Otoño 2026

Repositorio destinado a almacenar los proyectos, prácticas y ejercicios desarrollados durante la materia de **Programación Avanzada**.

## Proyectos

### 1. Simulador de Computadora - Simpletron

Simulador desarrollado en **Python** basado en la computadora virtual Simpletron.

El proyecto permitirá cargar y ejecutar programas escritos en **Simpletron Machine Language (SML)**, administrar una memoria de 100 posiciones y simular el funcionamiento de registros e instrucciones de una computadora.

📁 [Ver proyecto Simpletron](./Simulador-de-Computadora/)

**Estado:** Versión Base
