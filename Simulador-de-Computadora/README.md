# 🖥️ Simulador de Computadora - Simpletron

Proyecto desarrollado para la materia de **Programación Avanzada - Otoño 2026**.

El objetivo es desarrollar en **Python** un simulador de la computadora virtual **Simpletron**, capaz de cargar y ejecutar programas escritos en Simpletron Machine Language (SML).

---

## 📌 Versión actual

### Simpletron v1 - Versión Base

Esta versión establece las especificaciones iniciales y los requisitos que deberá cumplir el simulador durante su desarrollo.

🏷️ [Ver todas las versiones](../../releases)

---

## 🎯 Objetivo

El simulador deberá ser capaz de:

- Administrar una memoria de 100 posiciones.
- Cargar instrucciones escritas en SML.
- Ejecutar las 12 operaciones de Simpletron.
- Utilizar registros para controlar la ejecución.
- Realizar operaciones aritméticas.
- Realizar transferencias de control.
- Mostrar un vaciado completo de memoria.
- Detectar entradas inválidas y errores fatales.
