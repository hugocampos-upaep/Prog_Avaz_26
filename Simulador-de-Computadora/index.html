Un Simulador de Computadora

Simpletron

Versión Base

Planteamiento del proyecto

El proyecto consiste en desarrollar en Python un simulador funcional de una computadora llamada Simpletron.

El simulador permitirá cargar y ejecutar programas escritos en Simpletron Machine Language (SML), simulando el funcionamiento básico de la memoria, los registros y la ejecución de instrucciones.

Memoria

Simpletron contará con una memoria de 100 posiciones, numeradas desde 00 hasta 99.

En Python la memoria será representada mediante una lista: 

memory = [0] * 100

Cada posición podrá contener una instrucción SML o un dato.

Carga del programa

Las instrucciones SML serán introducidas por el usuario una por una y almacenadas en la memoria.

El valor 9999 indicará que ha terminado la fase de carga.

Los valores ingresados deberán encontrarse dentro del rango permitido por Simpletron.

Registros

Para simular el funcionamiento de la computadora se utilizarán los siguientes registros:

  • accumulator
  • instructionCounter
  • instructionRegister
  • operationCode
  • operand

Todos los registros comenzarán con un valor de cero.

Ciclo de ejecución

La ejecución comenzará en la posición 00 de la memoria. Simpletron obtendrá la instrucción correspondiente y la almacenará en el registro de instrucciones.

Posteriormente, la instrucción será separada en un código de operación y un operando. 

operationCode = instructionRegister // 100
operand = instructionRegister % 100

Operaciones SML

Simpletron deberá implementar las siguientes doce operaciones:

Código Operación
10READ
11WRITE
20LOAD
21STORE
30ADD
31SUBTRACT
32DIVIDE
33MULTIPLY
40BRANCH
41BRANCHNEG
42BRANCHZERO
43HALT

Vaciado de memoria

Al terminar la ejecución, el simulador deberá mostrar el contenido de los registros y las 100 posiciones de memoria.

Este procedimiento se conoce como Memory Dump.

Manejo de errores

El simulador deberá detectar errores durante su ejecución, como:

  • División entre cero.
  • Códigos de operación no válidos.
  • Desbordamiento del acumulador.
  • Datos fuera del rango permitido.

Cuando ocurra un error fatal, Simpletron deberá detener la ejecución y mostrar el vaciado de memoria.
